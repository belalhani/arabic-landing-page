# Landing Page (HTML / CSS / JS)

A responsive Arabic (RTL) landing page for freelance Python services: hero, services,
how I work, about, and a contact form with validation. Plain HTML, CSS and a little JavaScript,
no frameworks. Open `index.html` in a browser.

The contact form is a front-end demo: it validates and builds the message, it does not send email.

Built by Belal Hani.
